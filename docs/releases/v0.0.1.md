# TaskWatch v0.0.1 — early preview / 早期预览

## English

TaskWatch v0.0.1 is an early-preview DeepSeek Harness plugin for keeping task intent, visible execution evidence, and supervision advice separate.

- Three-layer goals keep the project purpose, current phase, and current task visible together; shared goal changes require confirmation.
- Tradeoff clarification and supervisor-only sidebar chat keep side conversations from rewriting the main Agent's task input.
- Bilingual sidebar support shows reports and known usage; unavailable usage remains marked as unknown.
- Measured scope: the exported bundle was installed and smoke-checked on DSH `0.1.5-rc.3` with Node.js `26.0.0`; startup, sidebar state, language switching, and model-settings UI were checked with zero model calls.
- Limit: live runtime supervision generation and coach behavior were not validated on DSH `0.1.5-rc.3`. This release makes no performance, benchmark, or quality claims.

Install with `dsh plugin --profile web add github:cjx12036/TaskWatch`. Review the source and use the consent flow before observation; model calls begin only after the relevant project and task permissions are given.

Repository: https://github.com/cjx12036/TaskWatch

Feedback: https://github.com/cjx12036/TaskWatch/issues/new?template=feedback.yml

## 中文

TaskWatch v0.0.1 是 DeepSeek Harness 的早期预览插件，用于将任务意图、可见执行证据与监督建议分开保存。

- 三层目标同时展示项目主旨、当前阶段与当前任务；共享目标修改需要确认。
- 取舍澄清和监督器专属侧栏对话，不会改写主 Agent 的任务输入。
- 双语侧栏显示报告与已知用量；无法取得的用量会明确标为未知。
- 已测范围：导出的 bundle 已在 DSH `0.1.5-rc.3` 和 Node.js `26.0.0` 上完成安装与冒烟检查；检查了启动、侧栏状态、语言切换和模型设置界面，全程零模型调用。
- 限制：DSH `0.1.5-rc.3` 上的实时监督生成与 coach 行为尚未验证。本版本不宣称性能、benchmark 或质量结果。

安装命令：`dsh plugin --profile web add github:cjx12036/TaskWatch`。请先审阅源码并完成同意流程；只有相应 project 与 task 已授权后才会开始模型调用。
